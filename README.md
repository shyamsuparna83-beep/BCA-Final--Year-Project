This is a full-stack web application developed as part of my internship project.
The project is divided into two main parts: Frontend and Backend.

 Technologies Used

 Frontend
- HTML
- CSS
- JavaScript  
- Bootstrap 

 Backend
- ASP.NET  
- C#
- SQL Server  
(mention any framework if used)

 How to Run the Project

 Frontend
1. Open the `frontend` folder
2. Open `index.html` in a browser  
   OR
3. Run using a local server (VS Code Live Server)

 Backend
1. Open the `backend` folder in **Visual Studio**
2. Restore required packages
3. Run the project using **IIS Express**
4. Backend will run on `http://localhost`

 Features
- User-friendly interface
- Backend integration with database
- CRUD operations
